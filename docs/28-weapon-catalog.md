# 28 — Weapon Catalog (The Arsenal)

> The full invented arsenal ([doc 09](09-weapons-combat.md)). Generic, invented
> manufacturers — **Maraca Arms, Ironwood Defense, Halsted, Sabal Ordnance** — so
> guns feel real without touching real trademarks ([doc 12](12-legal-distinctiveness.md)).
> Stats are relative tiers (★1–5). The design ethos: **violence is a tool, not the
> only tool** — the arsenal is built to support Quiet/Loud/Clever equally.

## Stat axes

- **Damage / Range / Fire-rate / Control / Concealment / Heat** (Heat = how much
  attention using it openly draws). Suppressed and non-lethal options exist across
  classes to make the **Quiet** lane real.

## Customization & legality

- **Attachments:** suppressors, optics, mags, grips, lasers — tuning damage,
  control, and especially **Heat/concealment**.
- **Legality matters:** open-carrying a rifle is Heat by itself; concealed
  sidearms and suppressed/non-lethal tools are a *playstyle*, not an afterthought
  ([doc 09](09-weapons-combat.md)).
- **Acquisition:** licensed shops (clean, limited), gray-market (anything, hot),
  loot/story rewards, and faction unlocks via rep ([doc 10](10-economy-progression.md)).

## Catalog design rules

- **The Quiet lane is fully armed** — suppressed, non-lethal, and gadget options
  exist for every situation, so pacifist/stealth play is never a handicap.
- **Heat is a real cost** — the loudest gun is rarely the smartest choice
  ([doc 01](01-vision.md)).
- **No fetishized gore or real-brand weapons** — impact through tension, generic
  manufacturers throughout ([doc 09](09-weapons-combat.md), [doc 12](12-legal-distinctiveness.md)).
